# GeoStandards.ch - öffentliche Repositories

Folgende Repositories werden durch GeoStandards.ch auf GitHub bereitgestellt:

- [`cog-best-practices`](https://github.com/geostandards-ch/cog-best-practices) - Best Practices für Cloud-Optimized GeoTIFF
- `cs2bim` - Umwandlung von Daten der Amtlichen Vermessung in das Format _ifc_  -> [Dokumentation](https://idibau.github.io/cs2bim/) durch FHNW Institut für Digitales Bauen
- [`DMAV-Testsuite`](https://github.com/geostandards-ch/DMAV-Testsuite) - Testsuite zum Testen von Constraints im Datenmodell DMAV
- [`DMAV-Validierungsmodell`](https://github.com/geostandards-ch/DMAV-Validierungsmodell) - Validierungsmodell zum Datenmodell DMAV
- [`doc_ilirepo`](https://github.com/geostandards-ch/doc_ilirepo) - Dokumentation zur Funktionsweise von INTERLIS Model Repositories
- [`doc_refhb24`](https://github.com/geostandards-ch/doc_refhb24) - Das INTERLIS Referenzhandbuch online
- [`eCH-0056`](https://github.com/geostandards-ch/eCH-0056) - Revisionsdokumentation zum Standard eCH-0056 _Anwendungsprofil Geodienste_
- [`gs-website`](https://github.com/geostandards-ch/gs-website) - Quellcode zur Website https://geostandards.ch
- [`ili2db_ilivalidator_de`](https://github.com/geostandards-ch/ili2db_ilivalidator_de) - Handbuch in Deutsch zu ili2db und ilivalidator
- [`ili2db_ilivalidator_fr`](https://github.com/geostandards-ch/ili2db_ilivalidator_fr) - Handbuch in Französisch zu ili2db und ilivalidator
- [`ogc-updates`](https://github.com/geostandards-ch/ogc-updates) - Artikel zu Entwicklungen bei OGC
- [`repo_models`](https://github.com/geostandards-ch/repo_models) - Revisionsdokumentation zum INTERLIS Model Repository unter models.interlis.ch
- [`repo_contribute`](https://github.com/geostandards-ch/repo_contribute) - Revisionsdokumentation zum INTERLIS Model Repository unter models.ilitools.ch
- [`webinar-stac`](https://github.com/geostandards-ch/webinar-stac) - Webinar zu STAC und verwandte OGC API Standards
- [`website-interlis-ch`](https://github.com/geostandards-ch/website-interlis-ch) - Issue-Tracker für https://www.interlis.ch
